# AX Job Agent - Development Rules

## 1. Jupyter Notebook 기본 작업 단위

Notebook의 모든 실습과 분석은 반드시 아래 3개의 Cell을 하나의 작업 단위로 사용한다.

### 1) 작업 계획 — Markdown Cell

실행할 코드의 목적과 확인할 내용을 먼저 설명한다.

포함할 내용:
- 이번 작업의 목적
- 무엇을 실행할 것인지
- 무엇을 확인할 것인지
- 성공 기준

### 2) 실제 코드 — Code Cell

현재 STEP에 필요한 최소한의 코드만 작성한다.

원칙:
- 한 Cell에 너무 많은 작업을 넣지 않는다.
- 초보자가 이해할 수 있는 크기로 작성한다.
- 실행 결과를 직접 확인할 수 있도록 한다.

### 3) 실행 결과 해석 / 분석 / 요약 — Markdown Cell

실제 실행 결과를 확인한 뒤 사람이 해석하여 기록한다.

포함할 내용:
- 실행 결과
- 결과가 의미하는 것
- 예상과 다른 부분
- 오류 또는 특이사항
- 다음 단계 진행 가능 여부

기본 패턴:

[Markdown]
작업 계획
↓
[Code]
실제 코드 실행
↓
[Markdown]
실행 결과 해석 / 분석 / 요약

중요 원칙:

코드만 실행하고 다음 단계로 넘어가지 않는다.
항상 실행 결과를 사람이 확인하고 해석한 뒤 다음 STEP으로 진행한다.
